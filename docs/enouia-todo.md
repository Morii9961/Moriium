## 明确不做

以下边界在 Morii 批准新的 ADR 并更新项目合同前继续有效：

- 评论。
- 没有明确读者价值的公开注册和用户资料系统。
- 未经 Phase 5 ADR 批准就把运行时管理后台、数据库或 API 接入生产。
- 统计分析与追踪脚本。
- 未经 Morii 单独批准的第三方服务。
