写下来的东西一旦公开，就很难说还完全属于自己。有人会原样搬走，有人会改几个字换个标题，有人只是想摘一句话存进笔记。复制限制挡不住任何一个下定决心的人，它能做的只是在读者按下复制时轻轻提醒一句：这段文字有作者。

## 限制了什么

这篇文章打开了复制限制。选中正文里的一段文字再复制，应该会看到一条提示，剪贴板里得到的也不是原文。

但它不应该妨碍正常的阅读：

- 用键盘在页面里移动焦点；
- 屏幕阅读器朗读正文；
- 搜索框、表单这类输入控件里的复制粘贴。

## 没有限制什么

代码是拿来用的，所以代码块不受限制。下面这段应该可以正常选中和复制，右上角的复制按钮也照常工作：

```bash
pnpm content:validate && pnpm build
```

## 它不是安全措施

复制限制只是一种态度。禁用脚本、打开开发者工具、或者直接看网页源代码，都能拿到全部文字。真正需要保密的内容，应该用加密文章，而不是靠这个开关。
