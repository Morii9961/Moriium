コールアウトは、ある一節を本文から切り出して「ここは語調が違う」と読者に伝えるためのものです。五つの種類は五つの語調に対応していて、落ち着いた補足から、立ち止まって読むべき警告までを表します。

## ディレクティブ記法

:::note
独自のタイトルを持たないノートです。タイトルには既定の文言が使われます。
:::

:::tip{title="書き方のコツ"}
結論を先に書き、理由は後から補います。読者が途中で離れても、少なくとも結論は持ち帰れます。
:::

:::important{title="公開の前に"}
公開する前に、次の三点を確認します。

1. 概要が 280 文字を超えていないこと
2. すべての画像に代替テキストがあること
3. 翻訳版が同じ `translationKey` を共有していること
:::

:::warning
外部の動画や音楽はクリックするまで通信しませんが、クリックした時点で相手側にリクエストが送られます。
:::

:::caution{title="暗号化記事"}
静的な暗号文はコピーしてオフラインでパスワードを推測できます。弱いパスワードは暗号化していないのと同じです。
:::

## コールアウト内の複雑な内容

:::tip{title="コードやリストも入れられます"}
- 一つ目
- 二つ目、`インラインコード` 付き

```ts
const kinds = ['note', 'tip', 'important', 'warning', 'caution'] as const;
```

ネタバレも入れられます：:spoiler[コールアウト内のネタバレも表示できます]。
:::

## インラインのネタバレ

この推理小説の結末は :spoiler[語り手自身が犯人だった] というものです。この一文は、クリックするか Enter キーまたはスペースキーを押すまで表示されません。

一つの段落に複数のネタバレを置くこともできます。犯人は :spoiler[執事]、動機は :spoiler[遺産]、決め手は :spoiler[出されなかった一通の手紙] です。

ネタバレには :spoiler[**太字** と `コード`] も含められます。
