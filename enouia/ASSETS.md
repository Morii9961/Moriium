# Assets

The room is a generated, fictional architectural scene created for Enouia on 2026-09-09 using the built-in image generator. It does not depict a private location or use a reference photograph.

Direction: a quiet coastal room with mineral plaster, sage tile, a blue curtain, a low bench, a closed notebook, and a glass of water. No people, logos, signage, or UI elements.

The generated 1536 × 1024 room image was encoded into local WebP derivatives at 1536 and 768 pixels wide. Its former square detail crop was retired from the public output when Morii requested more varied imagery.

On 2026-09-10, a separate fictional coastal stairway was generated for the third passage: worn stone steps, a metal handrail, submerged stone, and a small tuft of grass. It was generated independently, without the room image as a reference. `tidal-steps-1200.webp` and `tidal-steps-600.webp` are its responsive derivatives. The third passage describes visible details from this image, and identifies the location as imagined.

Encoding uses Sharp without metadata retention. The source PNGs stay outside the publishable tree; deployment requires only the checked-in WebP files.

`public/room-structure.svg` is an original vector interpretation traced against the generated room's window, sea horizon, bench, curtain, and tile geometry. `public/favicon.svg` and the remaining line work are original code-native graphics. Neither SVG contains scripts or external references.
